# TracksManager

Native macOS application for managing MKV audio tracks and subtitles.

## V1

- macOS / Apple Silicon
- MKV analysis without video re-encoding
- Audio and subtitle track management
- Batch processing architecture
- Human-readable processing stages and errors
- Subtitle conversion/synchronization planned
- Embedded third-party tools planned

## Development

The application is built with Swift and SwiftUI and targets macOS.

> The repository is currently in the foundation/prototype stage.
